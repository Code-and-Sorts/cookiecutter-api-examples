## How these are generated

Each branch is rendered from the template's `main` branch with two resources, `Cat` and `Dog`, that
share an `animals` container, and force-pushed by the template's
[`Publish Example Branches`](https://github.com/Code-and-Sorts/cookiecutter-api/blob/main/.github/workflows/publish-examples.yml)
workflow on every template change. The commit message on each branch names the template commit it
came from. Don't open pull requests against the example branches; change the template instead.

To generate your own project:

```console
pipx install copier
pipx inject copier jinja2-strcase jinja2-time
copier copy --trust gh:Code-and-Sorts/cookiecutter-api ./my-api
```
